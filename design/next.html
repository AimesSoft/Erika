画框版 全部界面重新设计 · 预览

一个画框，贯穿始终

播放器的「画框」思路推广到每一个界面：布局和动效是 Erika 自己的，控件全部交给各平台原生绘制。所以换到哪种设计语言都成立。每一屏都有一个自己的布局想法，但它们共用同一根线索——画面是一个画框：首页的舞台是画框，点进详情是画框在长大，开始播放是画框铺满窗口，返回时画框缩进侧栏。

动效只用位置、尺寸、缩放、透明度和圆角裁切这几种所有平台都能做的变换，全部是可打断的弹簧。每个窗口都可以直接点着用，右上角的按钮把这一节恢复原样。下面每一节都附了逐屏审查。

按 bern 的规矩，桌面、平板、手机、折叠屏、电视五种设备上每一屏的功能一样多，只有界面不同。设备开关会只列出那种设备上真的会出现的设计语言：鸿蒙有电脑、平板、手机和折叠屏；手机和平板是苹果、鸿蒙、Material、网页；折叠屏是 iPhone Duo、鸿蒙（Mate X）、Android 大折叠和网页；电视是 tvOS 和 Google TV。逐项对照见文末的 功能对等。

01

首次启动 · 小窗口长成真窗口

选起点时，右边的小窗口实时组装；点「开始使用」，这扇小窗口变形成你的 Erika。六步并成四步。

重新开始
原创点
  • 预览小窗口是整个引导的主角，选「纯粹 / 看番 / 全都要」时导航项当场弹进弹出。
  • 完成时不是关掉弹窗，而是小窗口长成主窗口（共享元素）。
常用功能
  • 多数人：开始 → 选「看番」→ 继续 → 开始使用，四次点击。
  • 「跳过」= 纯粹播放，之后随时能在设置里改。
动效（都能做到）
  • 弹窗 hero 弹出；导航项 jelly 进场；预览 wobble。
  • 完成：一个矩形的位置、尺寸、圆角走 hero 弹簧。
设计语言
  • 预设卡片、分段、色块、按钮都是原生控件。
  • 学院格和看板娘只在欢迎页出现（仪式时刻）。
审查记录
  • 发现：「推荐」标签被一条过宽的选择器挤到单独一行，底纹贯穿整张卡片；选中卡片的对勾看不见。→ 收窄选择器，已修。
  • 发现：桌面上预设卡片下面空着一大块，原来的「微调」一步也没了。→ 卡片下面加了全部模块的开关芯片（带依赖处理），点了自动切到「自己挑」。
  • 检查：完成时小窗口长成主窗口，主窗口按选择重新组装，侧栏只出现选中的页面。
  • 检查：手机上同样四步，预览移到卡片上方。
  • 检查：平板是居中的表单弹窗，电视全屏；电视上默认焦点在「开始」，一路回车就能走完四步。
02

纯粹模式 · 空画框

所有模块都关掉时，窗口就是一个还没放画面的画框。它和播放器退后时的画框一样大、在同一个位置，所以打开视频时画面直接填进来，控件出现在四周，没有任何跳动。

恢复
原创点
  • 空闲窗口 = 播放器的「无画面」状态，同一个画框贯穿空闲和播放。
  • 最近播放放在画框下面，正好是播放器控制行的位置。
常用功能
  • 「打开文件」在画框正中，1 次。
  • 最近播放 1 次；空格继续上次；直接把文件拖进窗口（原型里可以拖真视频）。
动效（都能做到）
  • 拖进来时画框描边变主题色并 jelly 晃一下。
  • 打开：画面淡入画框 → 控件淡入四周 → 3 秒后画框铺满窗口。
设计语言
  • 画框只是圆角矩形 + 虚线，圆角跟随外观的卡片圆角。
  • 按钮、最近播放都是原生控件。
审查记录
  • 发现：纯粹模式没有侧栏，播放器里点「返回」之后迷你播放器无处可放，视频就找不回来了。→ 改成画面退回空画框，这个视频排到「最近播放」第一个。
  • 检查：从最近播放打开时，播放器画框和空画框的坐标完全一致（103, 64 · 1074 × 604），没有跳动。
  • 检查：Fluent 的窗口按钮在纯粹模式下会挡住工具栏，只在这时给右上角留出 150px。
  • 发现：手机少了「打开文件夹」和「继续上次」，也没有对应「拖进窗口」的入口。→ 都补上，拖放对应系统的「打开方式 › Erika」；「继续上次」在每台设备上都是一个按钮（桌面另有空格键）。
  • 检查：平板和电视的空画框和各自播放器退后时的画框完全重合（平板 60, 76 · 1060 × 596，电视 200, 52 · 880 × 495）。
03

首页 · 舞台 + 今日时间轴

「继续观看」是一个舞台画框，其他在看的排在旁边，点一下互换上台。今天的新番挂在一条时间轴上，「现在」是一根主题色竖线：左边已更新，右边今晚稍后。

恢复
原创点
  • 舞台 + 换位：不用轮播，也不用一排同样大的卡片。
  • 今日更新按播出时间排在时间轴上，而不是网格。
常用功能
  • 继续看：点舞台或「继续播放」，1 次。
  • 换一部继续：悬停「也在看」那一行，点 ▶，1 次。
  • 今天的新番：时间轴上直接点海报。
动效（都能做到）
  • 换位：两张图交叉飞行（hero 弹簧）。
  • 时间轴进场：轴线展开、海报依次落下（jelly）、「现在」竖线弹出。
  • 点舞台：画框直接长成播放器。
设计语言
  • 舞台圆角 = 外观的卡片圆角；时间轴只有线和文字。
  • 「现在」用下划标注强调。
审查记录
  • 发现：「也在看」只有换位，继续另一部要点两次。→ 每一行悬停时缩略图上出现 ▶，直接播放仍然只要 1 次。
  • 发现：「现在 22:40」标签压在 23:30 的海报上。→ 海报整体下移 24px，标签放到海报上方。
  • 检查：换位动画结束后整页重排，滚动位置保留。
  • 发现：手机首页没有「详情」「打开」，「也在看」只能直接播放、不能换上舞台。→ 舞台下加「详情」，导航栏加「＋」打开文件；卡片点一下换上舞台，卡片右下角的 ▶ 直接播放。
  • 检查：平板没有悬停，▶ 常驻在缩略图右下角；电视上在那一行按 ← 就到 ▶。
04

番剧详情 · 胶片条，下一集永远在正中

海报从被点的卡片里长出来；头部铺一层从海报取出的颜色（不是模糊）。剧集是一条胶片，下一集停在正中并放大，越靠近中间的格子越大。

恢复
原创点
  • 胶片条：下一集在正中、离中心越近越大，滚动时像放大镜扫过。
  • 海报取色铺底，不依赖模糊。
常用功能
  • 「继续 第 n 话」和胶片正中那一格，都是 1 次。
  • 追番状态、评分是原生下拉，1 次打开。
动效（都能做到）
  • 海报共享元素（hero）。
  • 胶片放大 = 按滚动位置算的缩放。
  • 点某一集：那一格长成播放器。
设计语言
  • 标签页是原生分段控件；按钮、下拉原生。
  • 取色铺底在浅色和深色下都只占头部。
审查记录
  • 发现：取色铺底在 Fluent 的抬升内容层上有一道接缝（渐变终点是窗口底色，而不是透明）。→ 改成渐变到透明。
  • 发现：还没看过的番，胶片正中也写「继续」并带进度条。→ 改成「开始」，不显示进度。
  • 发现：正中放大的那一格压到左右邻居。→ 间距 16 → 30，放大 1.14 → 1.12。
05

播放器 · 画框（已定稿）

看片时画面铺满；一动鼠标，画面退后进画框，原生控件围在四周。字幕在画框里，永远不被挡；设置面板把画面推到一边。

恢复单独页面
原创点
  • 画面退后一步，控件在画框外面。
  • 手机横屏：两侧拇指区。
常用功能
  • 播放、快进退、弹幕开关、发弹幕、字幕、倍速都在一行。
  • 弹幕参数在分体按钮的右半边。
动效（都能做到）
  • 画框 hero 弹簧；控件淡入；返回时缩进迷你播放器。
设计语言
  • 见 播放器 · 画框 的控件对照表。
审查记录
  • 检查：桌面和手机都从被点的位置打开（手机先转横屏）；返回时缩进侧栏迷你播放器或标签栏上方的迷你条。
  • 检查：浅色窗口里播放器仍是深色，弹出菜单也跟着变深色。
  • 检查：红绿灯、Fluent 标题栏按钮、GNOME 关闭按钮在播放器里都保留。
  • 发现：手机进度条下面没有弹幕高峰。→ 改成轨道上的主题色小点，章节名在拖动提示里显示。
  • 检查：平板横放即全屏，画框按 1180 × 820 重排，控制行放在章节名下面；电视画框缩小一圈，控制行横跨整屏，控制层藏着时遥控器左右键直接快退快进，发弹幕是按钮（遥控器语音或手机输入）。
06

新番 · 手风琴周历

一周七天是七根柱子：选中的那天展开成列表，其余六天收成一摞海报，一眼看出每天有几部。点哪天，哪天就弹开。

恢复
原创点
  • 全周概览和单日详情在同一屏，不用切页、不用横向滚动。
  • 收起的柱子是一摞叠起来的海报。
常用功能
  • 今天默认展开；看别的日子点 1 次。
  • 点行进详情，详情里一键追番。
动效（都能做到）
  • 柱宽 bouncy 弹簧；展开后列表依次进场。
  • 手机上同一套手风琴改成竖向，高度走弹簧。
设计语言
  • 柱子是原生卡片 / 填充面，行是原生列表行。
审查记录
  • 改进：加了「明天」「后天」，扫一眼就知道离今天多远。
  • 检查：Material 浅色下展开的柱子用填充面，不用白卡，和 M3 的表面规则一致。
  • 检查：手机上改成竖向手风琴，行高走弹簧。
  • 发现：收起的柱子把海报一张压一张叠起来，封面都看不清。→ 改成一列互不重叠的小海报，每张下面写播出时间，放不下的显示「+n」（桌面、平板 4 张，电视 3 张）；手机竖向手风琴里的小海报也不再叠放。
07

媒体库 · 缩放墙 + 拼音索引

拖一下滑块（⌘± 或双指），海报墙从「目录」缩到「画廊」，每张海报沿弹簧滑到新位置。右边一条拼音索引，点字母直接滚过去。筛选和排序也是海报自己挪位。

恢复
原创点
  • 一个滑块管海报大小，小库看画廊，大库看目录。
  • 拼音索引条（像通讯录），点了那张海报会晃一下。
常用功能
  • 打开：点海报。
  • 找：索引条或 ⌘K；筛选：芯片 1 次；排序：原生下拉。
动效（都能做到）
  • 每张海报的 x / y / 宽是弹簧（FLIP 重排）。
  • 被筛掉的缩小淡出，留下的滑过去补位。
设计语言
  • 滑块、分段、芯片、下拉都是原生控件。
审查记录
  • 发现：手机默认只有两列，海报太大。→ 手机的海报尺寸范围改成 64–150，默认三列。
  • 发现：缩放滑块的手柄压到左边的小图标。→ 左右各留 8px。
  • 检查：缩到目录模式时标题自动隐藏；筛选、排序、切换「本地 / 服务器 / 共享」都是海报自己滑到新位置。
  • 发现：手机没有「管理」。→ 导航栏加文件夹按钮。电视上焦点停在海报大小滑块时，左右键调大小。
08

搜索 · 搜索框就地展开

⌘K 或点搜索框，搜索框自己长成结果面板（同一个物体），关掉时缩回去。结果按番剧、继续播放、设置、操作分组，选中框会滑过去。

恢复
原创点
  • 面板不是凭空出现，而是搜索框变形出来的。
  • 番剧结果直接给海报，一眼认出。
常用功能
  • ⌘K → 输入 → 回车；↑↓ 选择。
  • 设置项也能搜，回车直接打开那一节。
动效（都能做到）
  • 面板的位置、尺寸、圆角走 hero 弹簧。
  • 选中框 snappy 弹簧滑动。
设计语言
  • 面板用各平台浮层材质，输入框原生。
  • 手机上是「搜索」标签页。
审查记录
  • 发现：结果只有两三条时面板仍然 480px 高，下面空一大块。→ 面板高度跟着结果走，打字时用 bouncy 弹簧伸缩。
  • 检查：↑↓ 时选中框滑动，回车打开番剧、开始播放或跳到设置那一节。
  • 检查：手机上是「搜索」标签页，结果和桌面一样。
  • 检查：电视上搜索是顶栏第一个标签：左边屏幕键盘（拼音首字母、空格、删除、清空），右边结果，也接遥控器语音。
09

设置 · 可选功能 · 设置即预览

可选功能旁边是一扇实时变化的小窗口：开关一个模块，导航项弹进弹出，播放器条多出弹幕按钮；被连带开启的那一行会闪一下。整个应用也跟着变。

恢复
原创点
  • 开关的结果当场看得见，不用关掉设置去找。
  • 三个预设一键切换。
常用功能
  • 外观、播放、弹幕在侧栏前三项。
  • 搜索设置在侧栏顶部，也接入 ⌘K。
动效（都能做到）
  • 设置窗口从齿轮弹出（bouncy）。
  • 小窗口导航项 jelly 进场；依赖行闪一下。
设计语言
  • 全部是原生分组列表 + 开关 + 侧栏。
审查记录
  • 检查：关掉「媒体库」会连带关掉「网络媒体源」「局域网与远程」，这两行闪一下并弹出提示；侧栏和设置目录同时少掉对应的项。
  • 检查：libadwaita 是 boxed list，Fluent 是 SettingsCard，苹果是分组列表，Material 是填充面列表。
  • 发现：苹果外观里列表图标全是主题色方块，一屏好几个，违反「主题色少用」。→ 改成中性灰底。
  • 发现：手机设置首页没有账号和「搜索设置」，可选功能页没有三个预设。→ 都补上。电视上设置是全屏的。

插件市场 · 按钮就是进度条

点「获取」，按钮里面直接填满进度，装好变成「打开」并晃一下，不另外弹进度条。头图用学院格，这是少数的仪式时刻。

恢复
原创点
  • 进度在按钮里，视线不用离开。
常用功能
  • 获取 1 次；分类芯片 1 次。
动效（都能做到）
  • 按钮里一层宽度动画 + 完成时 wobble。
  • 换分类：卡片依次进场。
设计语言
  • 卡片、按钮、芯片原生；学院格只在头图。
审查记录
  • 检查：安装中的按钮不能再点，装好变成「打开」并晃一下，「已安装」计数同步。
  • 检查：学院格只出现在头图。
11

下载 · 行的底色就是进度

每一行的底色从左往右涨，底边一条主题色细线。下载完成后这一行收起来，移到「已完成」。

恢复
原创点
  • 不再一行一根进度条，行本身就是进度。
常用功能
  • 暂停 / 继续 1 次；添加任务 1 次；完成后直接播放。
动效（都能做到）
  • 底色宽度动画；完成时行高走 smooth 弹簧收起。
设计语言
  • 底色是中性填充，不是主题色大色块，只有底边那条细线用主题色。
审查记录
  • 发现：模拟下载太快，看一会儿就全完成了。→ 速度调慢到大约两分钟。
  • 检查：完成的那一行先收起再移到「已完成」，侧栏的下载数同步减少。
  • 检查：底色是中性填充，主题色只有底边那条细线。

迷你播放器 · 画框收进侧栏

每种设备上的设计语言：桌面六种都有（macOS、鸿蒙电脑、Windows、Linux、网页各自的样子）；平板和手机是苹果、鸿蒙、Material、网页（iPadOS / iOS、HarmonyOS、Android、网页），没有 Fluent 和 libadwaita；折叠屏是苹果（iPhone Duo）、鸿蒙（Mate X 一类）、Material（Galaxy / Pixel Fold）和网页；电视只有苹果和 Material（tvOS、Google TV）。切换设备时，当前的设计语言如果不适用，会自动回到苹果。

折叠屏的三种姿态：合上 = 外屏，就是一台手机（iPhone Duo 的外屏是 1.41:1 的护照形，系统栏和标签栏竖排在右侧，返回在最上面，常用操作在下面）。展开 = 左右两栏：左栏是当前页，右栏是点开的那一层，没点开时是「继续观看」的画框；折痕正好落在两栏中间，没有控件跨在折痕上（苹果的指南叫它分隔区域，要求偶数栏）。悬停 = 半开放在桌上：上半屏永远是画框，下半屏是手指能碰的那一半，播放时画面一直铺满上半屏，控件全在下半屏，所以画面不用退后。换姿态时停在同一页、同一层，正在放的视频接着放。苹果在 iPhone Duo 上把这叫做实时事件，鸿蒙对应的是折叠态和悬停态。

电视的操作方式：没有指针，焦点按空间位置移动，回车 = 点击，返回键逐层退回（菜单 → 播放器 → 弹窗 → 详情 → 首页）。焦点样式跟随外观：tvOS 是抬起放大、按钮变白；Google TV 是放大加描边、按钮反色。都只用缩放、阴影和颜色，不需要模糊。

整体结论：十二屏共用三条规则——画面是画框、控件交给系统、动效只用变换。每屏的原创点都来自布局（舞台、时间轴、胶片、手风琴、缩放墙、就地展开），不依赖任何平台独有的材质，所以换到苹果、鸿蒙、Material、Fluent、libadwaita 或网页都成立。审查中改掉的问题都写在各屏的「审查记录」里；主题色在每一屏都只出现在主要按钮、选中态、进度和「下划标注」上。
