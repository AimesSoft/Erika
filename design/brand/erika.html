第一版对比（选型记录）

下面是选型时的对比，保留作记录。

配色 日文 细线 底色

「点色」：ERIKA 用墨色，只有 エリカ（和细线）用品牌色。选「墨」时点色不起作用。

墨色与品牌色

每种颜色有浅底、深底两个值。深底用的是同色相的浅色，不是简单反白，这样在深色模式下仍然是那个颜色。

墨 + 一点品牌色

ERIKA 保持墨色，品牌色只落在 エリカ 上。整体最安静，颜色像落款的印章，只占很小的面积。

README

GitHub 的 README 可以用 <picture> 按访客的浅色、深色模式自动换图，所以每种配色各导出一张浅底用、一张深底用的 SVG。标题字宽 300–420px 比较合适。

小尺寸

字形

罗马大写的比例

E 最窄（约半个方格），R、K 中等，A 最宽。E 的中横比上下横短，下横最长，中横略高于正中，A 的横笔偏低。这些是碑刻大写的老规矩，看起来稳。

没有衬线，但有粗细

竖笔两端 23、中段收到 20，像轻微收腰；横笔 19 → 17。斜笔按笔顺分粗细：往右下走的笔画粗（R 腿、K 腿、A 右笔约 26），往右上走的笔画细（K 臂、A 左笔约 15）。这一点粗细变化让它典雅，而不是冷冰冰的几何字。

字距

比正文字距宽很多，五个字母之间的留白看起来一样大：两根竖笔相对（I–K）间距最大，开口相对（E–R、K–A）间距最小。

日文

エリカ 用等粗黑体笔画，字高约为 ERIKA 的 27%，笔画相对稍粗一点，缩小以后不会先消失。字距同样放宽，居中放在下方；需要更正式时两侧加细线。

石南紫

エリカ 在日文里就是欧石南（heather）这种花，石南紫取的是它的花色。颜色有来历，也最少见。

绀青

最端庄、最稳，接近墨色但带一点蓝；放在深色模式里也最不刺眼。

臙脂

最温暖、最有存在感，像印章的朱色偏暗一档；面积大了会显得重，更适合「点色」。
