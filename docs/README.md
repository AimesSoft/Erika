## 工程结构

```text
Bern.toml              应用清单：语言、外壳、模块、构建目标
erika-protocol/        核心的协议：打开、播放控制、设置、模块开关
erika-core/            核心的引擎（第一阶段是空实现）
erika-ui/              外壳界面：窗口、侧栏、播放层、纯粹模式、设置、首次启动
modules/<模块>/         可选模块，各有 protocol、core、ui 与 Bern.toml
docs/                  技术文档
design/                界面设计文档与原型
```

## 模块与设计稿的对照

设计稿第 04 章的 8 个可选模块，各是一个 Bern 模块，`optional = true`，可以在运行时开关；没开的模块不进导航、菜单和设置（P5），对应 Bern 模块关闭时它的贡献不存在。

| 模块 | id | 依赖 | 提供的页面与扩展点 |
| :-- | :-- | :-- | :-- |
| 弹幕 | `danmaku` | | 播放器的弹幕按钮、浮层与面板分页、设置一节 |
| 画质增强 | `enhance` | | 播放器面板「画面」分页里的超分选项 |
| 媒体库 | `library` | | 「媒体库」页面 |
| 追番 | `anime` | | 「首页」「新番」页面、番剧详情 |
| 账号同步 | `sync` | 追番 | 设置 › 账号 |
| 网络媒体源 | `sources` | 媒体库 | 媒体库 › 服务器 |
| 局域网与远程 | `remote` | 媒体库 | 媒体库 › 共享 |
| 下载 | `downloads` | | 「下载」页面 |

`Bern.toml` 中被依赖的模块写在依赖它的模块前面。

## 第一阶段的进度

2026-10-14，macOS：

- **外壳**：窗口 1280 × 800（最小 720 × 480），侧栏列出模块的页面（首页、新番、媒体库、下载），侧栏底部是迷你播放器、账号与设置；工具栏是搜索框（⌘K）与「打开」（⌘O 选视频）；播放器是盖在分栏之上的一层，始终深色，静置 3 秒画框铺满，一动指针退后、控件回来；没有页面时窗口是空画框。
- **追番模块**：首页的舞台（点击或「继续播放」开始播放）、也在看（点一下换上舞台，悬停出现 ▶）、今日时间轴（海报按播出时间挂在轴上，「现在」竖线）；详情页的取色铺底、海报、评分与标签、主要按钮、想看与更多菜单、胶片条（下一集停在正中、越近越大）、分段控件。
- **播放**：追番模块发出 `play` 事件，外壳的播放器响应；第一阶段不真正播放，画框里是剧照。返回时缩成侧栏底部的迷你播放器，点它长回去。
- 示例数据取自原型（`design/` 中的海报与剧照，作为随包资源）；命令都是空实现，只改界面要显示的状态。
- 媒体库、新番、下载与设置目前是占位页。

转场小样的结论（T1、T11）与新发现的 Bern 缺口见 [bern-extensions.md](bern-extensions.md) 第 17–22 项。
