## 工程结构

```text
Bern.toml              应用清单：语言、外壳、模块、构建目标

```

## Web 运行

使用包含本次 Web 后端扩展的相邻 Bern 仓库。在 Erika 根目录执行：

```sh
cargo build --manifest-path ../Bern/Cargo.toml -p bern-cli
../Bern/target/debug/bern run --target web_app --port 4173
```

访问 `http://127.0.0.1:4173/`，Ctrl-C 停止开发服务器。首次构建需要 Rust 的 `wasm32-unknown-unknown` 目标：

```sh
rustup target add wasm32-unknown-unknown
```

只构建静态文件：

```sh
../Bern/target/debug/bern build --target web_app --release
```

产物位于 `target/bern/web_app/`；通过 HTTP(S) 提供其中的 HTML、JavaScript、CSS、WASM 和 `resources/`，不要直接双击 HTML。引擎与模拟状态在浏览器的 WASM 内运行，不需要原生 Erika 进程，也不连接 macOS 的 CLI/IPC 会话。

引导完成状态、模块选择和主题按站点 origin 与应用标识保存在浏览器 localStorage。开发时保持同一个地址和端口；切换端口、浏览器或清除此站点数据会得到独立配置。原生 macOS 的配置不受影响。界面继续使用同一套 Bern 声明，播放、下载、更新与插件仍是第一阶段的状态模拟。

2026-10-15 的首轮 Chromium 检查覆盖 1280 × 800 桌面与 390 × 844 窄屏的引导、设置、搜索、媒体库、周历和模拟下载。窄屏引导正文滚动、底部按钮固定，进度圆点单独一行；设置窗口占满应用栏下方区域。这轮检查及逻辑测试未发现后续 Safari 实测暴露的滚动、尺寸和选中色问题，不能作为完整 Web 验收。

随后使用真实 Safari 27.0.1 验证并修复普通滚动区误用居中停靠、查询内容高度链断开、深层图片撑宽祖先及侧栏选中前景色配对问题。2026-10-16 复查确认媒体库显示 16 张海报，筛选「未看」得到 8 张；首页工具栏和右栏回到视口内，周历周一切换周三、设置通用切换外观均正常。侧栏最初只修复了可读性，仍错误使用灰色选中背景；再次修正后，Safari 深色绯红的主侧栏与设置侧栏均使用强调色实底，Chromium 另验浅色荧绿、浅色群青及选中/悬停状态。macOS 的原型配色通过目标样式保留。

Rail 放大图片画框的问题也已修复：Safari 在 1470 CSS px 宽度下确认舞台图右侧圆角和 28 px 间距恢复；Chromium 1470 × 754 下舞台按钮与图片均为 528 × 297。媒体库窄屏工具栏已修复，Chromium 390 × 844 和 360 × 780 下标题不换行、完整缩放控件两端可见、网格正常，页面没有横向溢出；这两项仅验证媒体库布局。Safari 手机布局及 Firefox 尚未实测。详细原因与验证范围见 [Web app 适配补充](bern-extensions.md#web-app-适配补充2026-10-15)。

## 播放内核 liberika

播放由 [liberika](https://github.com/AimesSoft/liberika) 完成，代码在 `erika-core/src/kernel/`：`kernel.rs` 是引擎看到的接口（打开、播放、跳转、轨道、截图等），`kernel/liberika.rs` 把 liberika 做成 Bern 的媒体内核。liberika 自己的线程为每个播放器持有一个 `PresenterRuntime`，在 `Video` 视图给出的 `CAMetalLayer` 上按显示刷新绘制画面、字幕和弹幕，没有视图时继续推进音频；它把播放状态报告给 Bern 的媒体中心（命令行 `erika media state --player-id video` 能看到同一个播放器），引擎在 250 ms 的播放节拍里读取位置、时长、轨道与结束状态。播放 3 秒后、暂停与缩小时截一张画面（480 宽 PNG，存在临时目录的 `erika-stills/`），作为迷你播放器、转场和最近播放的静帧。「更多 › 截图」（⌘S）按视频原尺寸把画面连同字幕存到「图片 › Erika」，文件名是标题加画面所在时间。

本地构建先准备 liberika 的原生依赖（FFmpeg、dav1d、libass 等，静态编译，一次即可）：

```sh
git clone https://github.com/AimesSoft/liberika ../liberika
brew install cmake meson ninja nasm pkg-config
cd ../liberika && cargo run -p xtask -- deps build --all --profile lgpl --target aarch64-apple-darwin
```

**字幕与弹幕都由 liberika 画在画面里**（2026-10-21），Erika 不再自己绘制：字幕是文件内嵌或外挂的轨道，字号对应 liberika 的字幕缩放；弹幕来自与视频同名、同目录的 `.xml` / `.json`（打开视频时自动加载）、播放设置或设置窗口里「挂载」的 B 站 xml 与弹弹play json，以及自己发送的弹幕（作为一条单独的轨）。弹幕设置存在引擎状态 `danmaku_settings` 里，按 liberika 的参数换算：字号滑块 20–40 点（中间 30），速度滑块是滚过画面的 14–6 秒，显示区域四分之一、一半、全屏，另有不透明度、合并重复、屏蔽顶部 / 底部 / 滚动和整体偏移。

**只接 liberika 支持的功能**：liberika 没有的就删掉入口，不在 Erika 里模拟，也不为此改 liberika。因此删去了字幕延迟、音频延迟、画面亮度、画面比例、HDR 开关（liberika 只在创建时选输出模式；设计稿本就写 HDR 自动启用、不提供开关）、屏蔽彩色弹幕和画中画；画面分页只在画质增强模块打开时出现，里面是超分辨率。弹弹play 匹配不是内核功能，属于弹幕模块，尚未实现，面板里原来写死的「已匹配」改为显示实际挂载的弹幕文件。模块里的示例剧集没有字幕和弹幕。

之后照常 `bern build --target macos`。Bern 会把 liberika 需要的系统框架（Metal、VideoToolbox、CoreAudio 等）交给 swiftc 链接。

目前只有 macOS 接了 liberika：iOS、tvOS 的视图已由 Bern 生成，需要先为模拟器编译 liberika 的依赖再实测；Windows、Linux、Android 等 Bern 给出 D3D、Wayland/X11、Android 的表面后接入；Web 上 liberika 没有播放后端。没接的平台仍按剧照模拟播放。没接的平台没有字幕和弹幕。

## 模块与设计稿的对照

设计稿第 04 章的 8 个可选模块，各是一个 Bern 模块，`optional = true`，可以在运行时开关；没开的模块不进导航、菜单和设置（P5），对应 Bern 模块关闭时它的贡献不存在。

| 模块 | id | 依赖 | 提供的页面与扩展点 |
| :-- | :-- | :-- | :-- |
| 弹幕 | `danmaku` | | 播放器的弹幕按钮、浮层与面板分页、设置一节 |
| 画质增强 | `enhance` | | 播放器面板「画面」分页里的超分选项 |
| 媒体库 | `library` | | 「媒体库」页面 |
| 追番 | `anime` | | 「首页」「新番」页面、番剧详情 |
| 账号同步 | `sync` | 追番 | 设置 › 账号 |
| 网络媒体源 | `sources` | 媒体库 | 媒体库 › 服务器 |
| 局域网与远程 | `remote` | 媒体库 | 媒体库 › 共享 |
| 下载 | `downloads` | | 「下载」页面 |

`Bern.toml` 中被依赖的模块写在依赖它的模块前面。

## 第一阶段的进度

2026-10-14，macOS：

- **外壳**：窗口 1280 × 800（最小 720 × 480），侧栏列出模块的页面（首页、新番、媒体库、下载），侧栏底部是迷你播放器、账号与设置；工具栏是搜索框（⌘K）与「打开」（⌘O 选视频）；播放器是盖在分栏之上的一层，始终深色，静置 3 秒画框铺满，一动指针退后、控件回来；没有页面时窗口是空画框。
- **追番模块**：首页的舞台（点击或「继续播放」开始播放）、也在看（点一下换上舞台，悬停出现 ▶）、今日时间轴（海报按播出时间挂在轴上，「现在」竖线）；详情页的取色铺底、海报、评分与标签、主要按钮、想看与更多菜单、胶片条（下一集停在正中、越近越大）、分段控件。
- **新番**：七天手风琴周历，沿用原型的 2026 年 10 月第 2 周示例数据，周一默认展开。收起列宽 86、列间距 8、高 560；四张小海报下显示播出时间，剩余条目显示「+n」。展开列填满剩余宽度、独立滚动；点行进入详情，返回时保留选中的日期。较窄窗口使用竖向手风琴。布局、内容和交互跟随设计稿，页面背景与明暗配色保留 macOS 原生默认（2026-10-14 确认）。

- **媒体库**：按原型的 16 张海报实现来源切换、观看状态筛选、最近观看 / 拼音 / 评分排序、缩放与字母索引；海报保持 2:3，观看进度覆盖在海报底部，点击进入详情并返回媒体库。排序菜单和管理按钮使用同高的胶囊液态玻璃。管理沿用原型的提示，仍未接入扫描或服务器。

## 播放器界面（2026-10-16）

播放器从外壳占位布局拆到 `erika-ui/src/player.rs`，以 `design/next-player.js` / `next.css` 的苹果桌面设计为基准。1280 × 800 下，显示控件时画框为 `(103, 64, 1074, 604.125)`，打开设置为 `(24, 114, 896, 504)`，右侧面板为 `(936, 64, 320, 604)`；闲置时画框为 `(0, 40, 1280, 720)`。较小桌面窗口等比缩放整个场景；手机横屏的两侧控制布局见下面的「iPhone 适配」。

- 顶栏、进度条、章节刻度与名称、弹幕高峰、上一集 / 后退十秒 / 播放暂停 / 前进十秒 / 下一集、字幕音轨菜单、倍速、按模块显示的增强菜单、弹幕快捷设置与发送入口均已接线。
- 右侧设置包含弹幕、字幕、画面、音频、播放五类；关闭弹幕模块时不显示对应分页。字幕选择、字号、弹幕滚动 / 暂停、透明度、区域和滚动 / 彩色屏蔽可以直接在示例画面中观察。播放器暂停、打开设置或输入时保持控制层可见。
- 时间由 250 ms 的 UI 模拟时钟更新；拖动进度不切换暂停状态。支持集数边界、末集停止和自动连播策略。返回保留侧栏迷你播放器；纯粹模式返回后暂停并保留回到播放器的入口。
- macOS 与 `web_app` 构建通过；核心 11 项测试通过。Bern 的编译器、SwiftUI、Web 和目标能力回归通过，Web 运行时 17 项测试包含拖动期间的引擎更新、负坐标和闲置计时不被播放时钟重置。实际检查了 macOS 1280 × 800 主画框和设置面板、Web 1280 × 800 两种画框坐标、分页、字幕字号、字幕切换、快进与倍速、迷你播放器返回；720 × 480 Web 页面没有横向或纵向溢出。

（2026-10-21 起，打开的文件与链接由 liberika 真播放，字幕、音轨、倍速、超分辨率与时间轴都来自内核，见「播放内核 liberika」；以下是那之前的范围，模块的示例剧集仍是如此。）仍遵守第一阶段的界面模拟范围：剧照代替视频，音频 / HDR / 画质增强等选项只更新状态，文件选择不解析媒体，截图、系统画中画和弹幕匹配给出预览提示。原生控件保留平台外观，纯图标按钮遵循无容器偏好。2026-10-17 已补齐首页舞台 → 播放器、播放器 ↔ 左下角迷你播放器的图片缩放移动动画，并验证快速反向切换、减少动态效果和小窗口恢复；实现与验证范围见扩展记录第 18 项及「播放器缩放转场」。真实视频纹理与其他播放入口的源图配对仍属于后续工作。

## iPhone 适配（2026-10-18）

以设计稿的手机原型（`app.html`，苹果设计、深色，390 × 844）为基准，在 iOS 26.5 的 iPhone 17e 模拟器上逐页量取对齐。布局与内容按原型的点数对齐；导航外观以 iOS 26 系统应用为准：返回是液态玻璃圆钮，顶栏右侧的圆钮为 44 点，相关按钮共用一个玻璃胶囊。

- **页面**：首页、新番、媒体库、搜索、详情、设置列表与各分页、首次引导四步。顶栏由外壳经 `[contributes]` 放进各模块页面留的 `page_header` 等插槽。量取偏差一般在 1 点以内，引导页 1–3 点。
- **横屏播放器**（`player_phone_scene`）：播放时窗口转为横屏（`Window(landscape:)`），`window.short` 选出 844 × 390 的场景，沉浸时内容铺满整个屏幕。画框三种位置与原型 `RECT.phone` 一致：铺满 `(75.5, 0, 693)`、显示控件 `(162.5, 48, 519)`、打开设置 `(16, 56, 512)`；两侧控件、进度条（章节点与弹幕高峰点）、顶栏、设置面板 `(544, 56, 284 × 322)` 都在原型位置，偏差 0–2.3 点。弹幕与字幕画在 693 × 390 的画布上随画框缩放（弹幕 17 点、五行、间距 30；字幕 19 点）。返回后转回竖屏。
- **迷你播放器**：`TabAccessory`，iOS 26.1 起是标签栏上方的系统附件；内容为 64 × 36 缩略图与进度、标题与集数时间、播放暂停与关闭。附件的位置和宽度由系统决定（比原型的 12 点边距略窄），按系统控件优先保留。
- **模块链接**：首页的「新番表 ›」与「全部 ›」用 `pages.new.show()`、`pages.library.show()` 切到对应页面。
- **时间**：分钟补足两位（`00:07`），秒数向下取整，与原型的 `fmt` 相同；桌面同样生效。

保留原生控件、因而与原型不同的地方：表单行文字为系统的 17 点、分组标题用系统样式；中文字形系统渲染约为 Chrome 的 0.947 倍；播放与进度条为系统控件（滑块、玻璃按钮）。设计文档 6.3 的触控尺寸（中 44、大 50）与手机原型（32 / 42）不一致，目前跟随原型。

为此新增或补全的 Bern 能力：`Row` 按项目宽度排、`Grid(cell_ratio:)`、页面内 `Search`、`Form` / `Section` 版式、`Modal(cover:)`、`Rail(overhang:)`、`ScrollView(open_at:)`、`scroll_origin`、应用自己的 `[contributes]`、`Window(landscape:)`、`window.short`、沉浸窗口铺满屏幕、`TabAccessory`、`pages.<页面>.show()`，以及 iOS 胶囊下拉与分段按钮的版式。各项的平台支持与验证范围见 Bern 的 `Docs/Reference/Platforms.md` 与 `Docs/Design.md`。GTK 于 2026-10-18 补上了 `Stack` 的背景与前景色样式，Linux 版从此可以构建：2026-10-19 起 `bern check` 六个目标都通过，Ubuntu 24.04 虚拟机上运行过（见上面的应用图标记录）。

## Apple TV（2026-10-20）

以设计稿的 TV 原型（`app.html` 选「电视」，`next.css` 的 `.nx[data-dev="tv"]` 一组规则，设计文档 3.1 与 6.2）为基准，用 Bern 新增的 tvOS 目标实现（`erika-ui/src/tv.rs` 与各页面的 `window.tv` 分支）。整个画面是原型的 1280 × 720 场景，放大 1.5 倍铺满 1920 × 1080 的屏幕（`Stack(under_bars: true)` 里的 `ScaleBox`）；遥控器移动焦点。电视用原型的电视字号（`text` 块的 `tv:`）。

- **外壳**：顶部是 tvOS 的系统标签栏：搜索在最前，只是放大镜（`Tab(display: icon)`，读屏仍读「搜索」），之后是首页、新番、媒体库、下载（按启用的模块），页面标签只有文字；每页在标签栏下 80 点开始。右上角（离右边 48、离顶 17，相隔 10）依次是头像、「打开」与设置。「打开」只有打开链接（电视没有文件可选）。播放中收起时，小窗在右下角（300 宽，离右 40、离底 32）。
- **页面**：页边距 56（`.x-page`）。首页舞台 560 × 315，右栏在 x 652，「也在看」行 80 高、缩略图 120 × 68，角上是播放圆钮；新番的一周 500 高，展开的一天 604 宽；媒体库海报从 112 到 230 宽（默认约 154，一行六张），缩放滑块 132 宽，筛选 40 高，字母索引 26 宽；详情与桌面同一布局。
- **搜索**：标题后写着「用遥控器选拼音首字母，或按住遥控器的语音键说出番名」；左边 440 宽的屏幕键盘（A–Z 每行七个 56 × 52，空格、删除、清空两格宽），右边 40 点外是 52 高的搜索框与结果（未输入就列出：番剧海报 96 宽、继续播放、设置、操作）。搜索框也能用系统键盘与听写。
- **设置**：铺满屏幕。左边 300 宽的面板列出各页（46 高、无图标，起始焦点在「通用」），右边是页标题（22 点）与该页的表单，右上角关闭；返回键也关闭。设置的搜索在电视上由搜索页承担（搜索结果有「设置」一组）。
- **播放器**（`player_tv_scene`）：画框比桌面小，铺满 `(0, 0, 1280)`、显示控件 `(200, 52, 880 × 495)`、打开设置 `(40, 100, 784 × 441)`；控制条横跨屏幕（x 64、宽 1152，打开设置时 x 40、宽 1200，y 624、高 56），进度条在画框下，设置面板在 `(848, 52, 392 × 548)`。控制条显示时起始焦点在暂停；隐藏时一个铺满画面、不画焦点的按钮接住焦点：左右快退快进 10 秒且不唤醒控制条，上下唤醒控制条，按下暂停或继续。弹幕用「发弹幕」按钮（纸飞机）打开画框下的输入框。
- **遥控按键**：返回键在详情页关闭详情，在播放器里依次关闭设置面板、回到画框、收起播放器；播放/暂停键切换播放。
- **首次引导**：铺满屏幕的 1280 × 720（左半是 640 × 648 的格纹与 Logo，底部 72 高、按钮 46 高），起始焦点在「开始」，之后每步在「继续」；Logo 用静态图片（tvOS 没有 WebKit）。
- **纯粹模式**：没有标签栏，画框在 `(200, 52, 880 × 495)`，中间是「打开链接…」与「继续上次」，右上角是设置。
