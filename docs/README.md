## 工程结构

```text
Bern.toml              应用清单：语言、外壳、模块、构建目标
erika-protocol/        核心的协议：打开、播放控制、设置、模块开关
erika-core/            核心的引擎（第一阶段是空实现）
erika-ui/              外壳界面：窗口、侧栏、播放层、纯粹模式、设置、首次启动
modules/<模块>/         可选模块，各有 protocol、core、ui 与 Bern.toml
docs/                  技术文档
design/                界面设计文档与原型
```

## Web 运行

使用包含本次 Web 后端扩展的相邻 Bern 仓库。在 Erika 根目录执行：

```sh
cargo build --manifest-path ../Bern/Cargo.toml -p bern-cli
../Bern/target/debug/bern run --target web_app --port 4173
```

访问 `http://127.0.0.1:4173/`，Ctrl-C 停止开发服务器。首次构建需要 Rust 的 `wasm32-unknown-unknown` 目标：

```sh
rustup target add wasm32-unknown-unknown
```

只构建静态文件：

```sh
../Bern/target/debug/bern build --target web_app --release
```

产物位于 `target/bern/web_app/`；通过 HTTP(S) 提供其中的 HTML、JavaScript、CSS、WASM 和 `resources/`，不要直接双击 HTML。引擎与模拟状态在浏览器的 WASM 内运行，不需要原生 Erika 进程，也不连接 macOS 的 CLI/IPC 会话。

引导完成状态、模块选择和主题按站点 origin 与应用标识保存在浏览器 localStorage。开发时保持同一个地址和端口；切换端口、浏览器或清除此站点数据会得到独立配置。原生 macOS 的配置不受影响。界面继续使用同一套 Bern 声明，播放、下载、更新与插件仍是第一阶段的状态模拟。

2026-10-15 的首轮 Chromium 检查覆盖 1280 × 800 桌面与 390 × 844 窄屏的引导、设置、搜索、媒体库、周历和模拟下载。窄屏引导正文滚动、底部按钮固定，进度圆点单独一行；设置窗口占满应用栏下方区域。这轮检查及逻辑测试未发现后续 Safari 实测暴露的滚动、尺寸和选中色问题，不能作为完整 Web 验收。

随后使用真实 Safari 27.0.1 验证并修复普通滚动区误用居中停靠、查询内容高度链断开、深层图片撑宽祖先及侧栏选中前景色配对问题。2026-10-16 复查确认媒体库显示 16 张海报，筛选「未看」得到 8 张；首页工具栏和右栏回到视口内，周历周一切换周三、设置通用切换外观均正常。侧栏最初只修复了可读性，仍错误使用灰色选中背景；再次修正后，Safari 深色绯红的主侧栏与设置侧栏均使用强调色实底，Chromium 另验浅色荧绿、浅色群青及选中/悬停状态。macOS 的原型配色通过目标样式保留。

Rail 放大图片画框的问题也已修复：Safari 在 1470 CSS px 宽度下确认舞台图右侧圆角和 28 px 间距恢复；Chromium 1470 × 754 下舞台按钮与图片均为 528 × 297。媒体库窄屏工具栏已修复，Chromium 390 × 844 和 360 × 780 下标题不换行、完整缩放控件两端可见、网格正常，页面没有横向溢出；这两项仅验证媒体库布局。Safari 手机布局及 Firefox 尚未实测。详细原因与验证范围见 [Web app 适配补充](bern-extensions.md#web-app-适配补充2026-10-15)。

## 模块与设计稿的对照

设计稿第 04 章的 8 个可选模块，各是一个 Bern 模块，`optional = true`，可以在运行时开关；没开的模块不进导航、菜单和设置（P5），对应 Bern 模块关闭时它的贡献不存在。

| 模块 | id | 依赖 | 提供的页面与扩展点 |
| :-- | :-- | :-- | :-- |
| 弹幕 | `danmaku` | | 播放器的弹幕按钮、浮层与面板分页、设置一节 |
| 画质增强 | `enhance` | | 播放器面板「画面」分页里的超分选项 |
| 媒体库 | `library` | | 「媒体库」页面 |
| 追番 | `anime` | | 「首页」「新番」页面、番剧详情 |
| 账号同步 | `sync` | 追番 | 设置 › 账号 |
| 网络媒体源 | `sources` | 媒体库 | 媒体库 › 服务器 |
| 局域网与远程 | `remote` | 媒体库 | 媒体库 › 共享 |
| 下载 | `downloads` | | 「下载」页面 |

`Bern.toml` 中被依赖的模块写在依赖它的模块前面。

## 第一阶段的进度

2026-10-14，macOS：

- **外壳**：窗口 1280 × 800（最小 720 × 480），侧栏列出模块的页面（首页、新番、媒体库、下载），侧栏底部是迷你播放器、账号与设置；工具栏是搜索框（⌘K）与「打开」（⌘O 选视频）；播放器是盖在分栏之上的一层，始终深色，静置 3 秒画框铺满，一动指针退后、控件回来；没有页面时窗口是空画框。
- **追番模块**：首页的舞台（点击或「继续播放」开始播放）、也在看（点一下换上舞台，悬停出现 ▶）、今日时间轴（海报按播出时间挂在轴上，「现在」竖线）；详情页的取色铺底、海报、评分与标签、主要按钮、想看与更多菜单、胶片条（下一集停在正中、越近越大）、分段控件。
- **新番**：七天手风琴周历，沿用原型的 2026 年 10 月第 2 周示例数据，周一默认展开。收起列宽 86、列间距 8、高 560；四张小海报下显示播出时间，剩余条目显示「+n」。展开列填满剩余宽度、独立滚动；点行进入详情，返回时保留选中的日期。较窄窗口使用竖向手风琴。布局、内容和交互跟随设计稿，页面背景与明暗配色保留 macOS 原生默认（2026-10-14 确认）。
- **播放**：追番模块发出 `play` 事件，外壳的播放器响应；第一阶段不真正播放，画框里是剧照。返回时缩成侧栏底部的迷你播放器，点它长回去。
- **搜索**：点击工具栏里的搜索框或按 ⌘K，搜索框就地展开成搜索面板（设计 10.8 / T17）；面板用系统浮层材质，输入框是原生文本框，「打开」按设计稿放在搜索框右边；按原型的 640 × 480 上限、56 pt 输入栏、海报与分组结果布局，结果减少时面板收缩。支持番名与拼音首字母、继续播放、设置和操作入口，上下键选择、回车执行、Escape 与点外部关闭；窄窗口内限制尺寸，关闭模块后移除相应结果。设置结果目前打开设置窗口，尚未定位到具体设置分区。
- **媒体库**：按原型的 16 张海报实现来源切换、观看状态筛选、最近观看 / 拼音 / 评分排序、缩放与字母索引；海报保持 2:3，观看进度覆盖在海报底部，点击进入详情并返回媒体库。排序菜单和管理按钮使用同高的胶囊液态玻璃。管理沿用原型的提示，仍未接入扫描或服务器。
- 示例数据取自原型（`design/` 中的海报与剧照，作为随包资源）；命令都是空实现，只改界面要显示的状态。

## 播放器界面（2026-10-16）

播放器从外壳占位布局拆到 `erika-ui/src/player.rs`，以 `design/next-player.js` / `next.css` 的苹果桌面设计为基准。1280 × 800 下，显示控件时画框为 `(103, 64, 1074, 604.125)`，打开设置为 `(24, 114, 896, 504)`，右侧面板为 `(936, 64, 320, 604)`；闲置时画框为 `(0, 40, 1280, 720)`。较小桌面窗口等比缩放整个场景；手机横屏的两侧控制布局见下面的「iPhone 适配」。

- 顶栏、进度条、章节刻度与名称、弹幕高峰、上一集 / 后退十秒 / 播放暂停 / 前进十秒 / 下一集、字幕音轨菜单、倍速、按模块显示的增强菜单、弹幕快捷设置与发送入口均已接线。
- 右侧设置包含弹幕、字幕、画面、音频、播放五类；关闭弹幕模块时不显示对应分页。字幕选择、字号、弹幕滚动 / 暂停、透明度、区域和滚动 / 彩色屏蔽可以直接在示例画面中观察。播放器暂停、打开设置或输入时保持控制层可见。
- 时间由 250 ms 的 UI 模拟时钟更新；拖动进度不切换暂停状态。支持集数边界、末集停止和自动连播策略。返回保留侧栏迷你播放器；纯粹模式返回后暂停并保留回到播放器的入口。
- macOS 与 `web_app` 构建通过；核心 11 项测试通过。Bern 的编译器、SwiftUI、Web 和目标能力回归通过，Web 运行时 17 项测试包含拖动期间的引擎更新、负坐标和闲置计时不被播放时钟重置。实际检查了 macOS 1280 × 800 主画框和设置面板、Web 1280 × 800 两种画框坐标、分页、字幕字号、字幕切换、快进与倍速、迷你播放器返回；720 × 480 Web 页面没有横向或纵向溢出。

仍遵守第一阶段的界面模拟范围：剧照代替视频，音频 / HDR / 画质增强等选项只更新状态，文件选择不解析媒体，截图、系统画中画和弹幕匹配给出预览提示。原生控件保留平台外观，纯图标按钮遵循无容器偏好。2026-10-17 已补齐首页舞台 → 播放器、播放器 ↔ 左下角迷你播放器的图片缩放移动动画，并验证快速反向切换、减少动态效果和小窗口恢复；实现与验证范围见扩展记录第 18 项及「播放器缩放转场」。真实视频纹理与其他播放入口的源图配对仍属于后续工作。

## iPhone 适配（2026-10-18）

以设计稿的手机原型（`app.html`，苹果设计、深色，390 × 844）为基准，在 iOS 26.5 的 iPhone 17e 模拟器上逐页量取对齐。布局与内容按原型的点数对齐；导航外观以 iOS 26 系统应用为准：返回是液态玻璃圆钮，顶栏右侧的圆钮为 44 点，相关按钮共用一个玻璃胶囊。

- **页面**：首页、新番、媒体库、搜索、详情、设置列表与各分页、首次引导四步。顶栏由外壳经 `[contributes]` 放进各模块页面留的 `page_header` 等插槽。量取偏差一般在 1 点以内，引导页 1–3 点。
- **横屏播放器**（`player_phone_scene`）：播放时窗口转为横屏（`Window(landscape:)`），`window.short` 选出 844 × 390 的场景，沉浸时内容铺满整个屏幕。画框三种位置与原型 `RECT.phone` 一致：铺满 `(75.5, 0, 693)`、显示控件 `(162.5, 48, 519)`、打开设置 `(16, 56, 512)`；两侧控件、进度条（章节点与弹幕高峰点）、顶栏、设置面板 `(544, 56, 284 × 322)` 都在原型位置，偏差 0–2.3 点。弹幕与字幕画在 693 × 390 的画布上随画框缩放（弹幕 17 点、五行、间距 30；字幕 19 点）。返回后转回竖屏。
- **迷你播放器**：`TabAccessory`，iOS 26.1 起是标签栏上方的系统附件；内容为 64 × 36 缩略图与进度、标题与集数时间、播放暂停与关闭。附件的位置和宽度由系统决定（比原型的 12 点边距略窄），按系统控件优先保留。
- **模块链接**：首页的「新番表 ›」与「全部 ›」用 `pages.new.show()`、`pages.library.show()` 切到对应页面。
- **时间**：分钟补足两位（`00:07`），秒数向下取整，与原型的 `fmt` 相同；桌面同样生效。

保留原生控件、因而与原型不同的地方：表单行文字为系统的 17 点、分组标题用系统样式；中文字形系统渲染约为 Chrome 的 0.947 倍；播放与进度条为系统控件（滑块、玻璃按钮）。设计文档 6.3 的触控尺寸（中 44、大 50）与手机原型（32 / 42）不一致，目前跟随原型。

为此新增或补全的 Bern 能力：`Row` 按项目宽度排、`Grid(cell_ratio:)`、页面内 `Search`、`Form` / `Section` 版式、`Modal(cover:)`、`Rail(overhang:)`、`ScrollView(open_at:)`、`scroll_origin`、应用自己的 `[contributes]`、`Window(landscape:)`、`window.short`、沉浸窗口铺满屏幕、`TabAccessory`、`pages.<页面>.show()`，以及 iOS 胶囊下拉与分段按钮的版式。各项的平台支持与验证范围见 Bern 的 `Docs/Reference/Platforms.md` 与 `Docs/Design.md`。Erika 目前还不能构建 Linux 版：GTK 不支持 `Stack` 的背景与前景色样式，构建检查直接拒绝。
